# Nexora

Create a modern full-stack social media mobile app inspired by Instagram with a premium black + gradient UI, smooth animations, ultra-fast performance, and professional design. The app name should be customizable. Build everything production-ready with clean architecture, responsive layouts, secure authentication, and real-time features.



MAIN FEATURES:



1. AUTHENTICATION SYSTEM



- Signup using:

  • Full Name

  • Username

  • Gmail / Email

  • Password

- Login system with JWT/Firebase authentication

- Forgot password via email

- Username must be unique

- Secure encrypted passwords

- Auto login after signup

- Logout option

- Edit profile option



2. USER PROFILE SYSTEM



- Profile photo upload

- Bio section

- Username display

- Followers count

- Following count

- Total posts count

- Profile verification badge support

- Editable profile

- Public and private account option

- Show user posts in grid layout like Instagram



3. FRIEND REQUEST / FOLLOW SYSTEM



- Users can search usernames instantly

- Send follow/friend request

- Accept or reject requests

- Once accepted, both users can chat

- Follow / Unfollow button

- Real-time followers and following updates

- Notification when someone follows or accepts request



4. REAL-TIME CHAT SYSTEM



- Personal one-to-one chats

- Send text messages

- Send images

- Online/offline indicator

- Seen message status

- Typing indicator

- Chat list with latest messages

- Delete chat option

- Real-time messaging using Socket.IO or Firebase

- Smooth modern chat UI like Instagram DM



5. POSTS SYSTEM



- Upload image posts

- Add captions

- Like posts

- Comment system

- Save/bookmark posts

- Share posts internally

- Double tap to like animation

- Post delete/edit option

- Feed page with infinite scrolling

- Explore page with trending posts



6. SEARCH SYSTEM



- Search users by username

- Live search suggestions

- Search results with profile images

- Open profile directly from search

- Search bar animation and premium UI



7. NOTIFICATION SYSTEM



- Real-time notifications for:

  • Likes

  • Comments

  • Follow requests

  • Accepted requests

  • Messages

- Notification badge count

- Beautiful notification page UI



8. SETTINGS PAGE



- Dark mode support

- Edit account details

- Change password

- Privacy settings

- Block users

- Logout option



9. UI / UX REQUIREMENTS



- Exact premium feel inspired by Instagram

- Smooth transitions and animations

- Glassmorphism + gradient effects

- Bottom navigation bar

- Splash screen with logo animation

- Skeleton loading effects

- Pull to refresh

- Fully responsive design

- Fast loading optimization

- Professional typography

- Beautiful modern icons



10. TECH STACK

    Frontend:



- React Native / Flutter

- TailwindCSS or modern UI framework

- Redux / Context API for state management



Backend:



- Node.js + Express

- MongoDB / Firebase

- Socket.IO for chats

- Cloudinary/Firebase Storage for images



11. SECURITY & PERFORMANCE



- Protected APIs

- Rate limiting

- Secure authentication

- Optimized database queries

- Image compression

- Lazy loading

- Error handling everywhere



12. EXTRA REQUIREMENTS



- Clean folder structure

- Production-ready code

- Modular components

- Smooth animations everywhere

- Real-time sync

- Modern app icon

- Premium onboarding screens

- Everything should feel ultra premium and polished



DO NOT ADD:



- Stories

- Reels

- Voice/Video Calls



The final app should feel like a real premium Instagram alternative focused on posts, followers, profiles, search, and real-time chatting with an ultra-modern UI and smooth user experience.
